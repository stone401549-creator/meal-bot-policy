개인정보 처리방침

시행일: 2026년 10월 27일 · 마지막 수정일: 2026년 10월 27일

이 문서는 현재 식사 추천 봇의 /점메추, /저메추 및 버튼 기능을 구현한 코드 기준으로 작성되었습니다. 기능 또는 호스팅 방식을 변경할 경우 처리방침도 수정해야 합니다.

1. 처리하는 정보와 목적

봇은 명령어와 버튼 상호작용을 제공하는 과정에서 디스코드로부터 전달되는 다음 정보를 이용합니다.

  • 디스코드 사용자 ID: 명령어를 실행한 사람만 추천 버튼을 조작할 수 있도록 확인
  • 상호작용 내용: 점심·저녁 명령어, 밥·면·빵 종류 선택, 다시 추천 버튼 선택에 따른 응답 생성
  • 상호작용 및 메시지 식별 정보: 요청한 메시지의 화면을 갱신하고 버튼을 비활성화하는 기능 수행
  • 서버·채널 정보: 디스코드에서 해당 상호작용에 응답하기 위해 필요한 범위에서 처리

현재 코드에는 음식 취향 프로필, 명령어 이용 이력, 일반 채팅 내용, 위치 정보 또는 결제 정보를 별도 파일·데이터베이스에 기록하는 기능이 없습니다.

2. 처리 근거 및 이용 방식

이용자가 명령어와 버튼을 직접 실행하면 요청받은 추천 기능을 제공하기 위해 필요한 범위에서 상호작용 정보를 처리합니다. 명령어 사용 여부는 이용자가 선택할 수 있습니다.

3. 보유 및 보관 기간

현재 구현에서는 버튼 동작 확인을 위한 사용자 ID와 메뉴 선택 상태를 봇 실행 메모리에서 일시적으로 사용하며, 버튼의 유효 시간은 약 5분입니다. 봇 자체는 해당 정보를 영구 저장하는 사용자 이력 데이터베이스를 운영하지 않습니다. 다만, 디스코드 채널에 전송된 명령어 응답 메시지와 디스코드가 자체적으로 보관하는 데이터는 디스코드의 정책 및 서버 설정에 따라 남을 수 있습니다.

4. 제3자 제공 및 외부 서비스

봇은 기능 제공을 위해 디스코드의 API와 서비스를 사용합니다. 현재 봇 코드에는 수집된 이용자 정보를 광고업체 등에 판매하거나 외부 분석 서비스로 전송하는 기능이 없습니다. 디스코드 자체의 정보 처리에 대해서는 디스코드 개인정보 처리방침을 참고하세요.

5. 이용자 권리와 삭제 요청

이용자는 봇 사용을 중단하거나, 서버 권한이 있는 경우 봇 설치를 제거할 수 있습니다. 디스코드에 게시된 봇의 응답 메시지 삭제는 해당 서버 및 디스코드의 권한·기능에 따릅니다. 개인정보 처리 및 삭제 요청에 관한 문의는 아래 연락처로 접수할 수 있습니다.

6. 안전성 확보

운영자는 봇 인증 토큰을 비공개 설정 파일로 관리하고, 서비스 제공에 불필요한 개인정보 저장을 최소화하도록 운영합니다. 코드 변경이나 외부 호스팅 도입 시 접근 권한과 보관 방식도 점검합니다.
